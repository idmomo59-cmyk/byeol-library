# 별의 서재 v5.2 — 무료 웹 호스팅 배포용

기존 v5.1 화면을 그대로 사용하며 Render의 **Free Web Service**로 배포할 수 있도록 `render.yaml`과 실행 설정을 추가했습니다. 실제 배포는 운영자 Render/GitHub 계정에서 승인해야 하며, 이 파일만으로 사이트가 공개되는 것은 아닙니다.

## 배포 순서

1. ZIP을 풀고 `byeol-free-deploy` 폴더 안의 파일 전체를 새 **GitHub 저장소**의 최상위에 업로드합니다. `index.html`, `server.js`, `render.yaml`, `package.json`이 루트에 있어야 합니다.
2. [Render Dashboard](https://dashboard.render.com/)에서 **New > Blueprint**를 선택하고 GitHub 저장소를 연결합니다.
3. `render.yaml`을 읽어 생성할 **Free** 웹 서비스를 확인하고 배포합니다. Render의 무료 서비스 제공 여부와 조건은 계정/시점에 따라 바뀔 수 있습니다. 유료 플랜이 표시되면 승인하지 마세요.
4. Render 환경변수 `OPENAI_API_KEY`에 운영자 API 키를 **비공개로** 설정합니다. 이 값을 GitHub, HTML, 채팅에 넣지 마세요. 설정 전에도 웹사이트 UI는 열리지만 AI 풀이는 작동하지 않습니다.
5. Render가 발급한 `https://...onrender.com` 주소로 접속해 생년월일 입력 → 정통 사주풀이 → AI 상세 풀이를 테스트합니다. `/api/health`는 서버 동작과 API 키 설정 여부만 표시합니다.

## 무료의 의미와 제한

- **방문자 이용료 0원**. Render의 무료 호스팅 범위 내에서 호스팅 비용을 0원으로 시작할 수 있습니다.
- **OpenAI API는 무료가 아닙니다.** 실제 AI 풀이를 활성화하면 운영자에게 호출 비용이 발생합니다. 완전한 0원 운영을 원하면 `OPENAI_API_KEY`를 설정하지 않고 AI 버튼은 비활성 상태로 유지해야 합니다.
- Render 무료 인스턴스는 유휴 시 절전 상태로 전환되어 첫 접속이 느릴 수 있으며, 리소스·사용 시간 등 제한이 있습니다. 무료 플랜 정책은 배포 시 확인하세요.
- 현재 IP별/전체 호출 제한은 **서버 메모리 기반**이라 재시작이나 인스턴스 변경 시 초기화됩니다. 악의적 사용으로 인한 과금을 완전히 막을 수 없습니다. 공개 운영 전에 영속적인 사용량 제한·봇 방어·API 예산 알림을 추가해야 합니다.
- 기존 만세력은 정밀 절기/시간 보정 검증 전의 베타입니다. 다른 메뉴 점수 및 해석은 예시 데이터입니다.

## 로컬 테스트
